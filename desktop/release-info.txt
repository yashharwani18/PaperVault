PaperVault for Windows

Includes the document engine, Python runtime and local search model. This build runs search and indexing on the CPU. You do not need to install Python or Node separately.

Setup installs for your Windows account. Your library is stored separately under %LOCALAPPDATA%\LocalKnowledgeLibrary\library. Upgrade and uninstall preserve this library and your original PDFs.

No scan begins until you choose to scan this computer or connect a folder. Scanning indexes documents in place. Normal indexing and search run offline.

This installer is unsigned.
