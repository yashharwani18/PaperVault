# Phase 3 protocol (written before ranking)

Use the same 20 PDFs and positive physical-page labels for every method. The coding agent inspected extracted source pages to create these judgments; no independent human annotation or exhaustive relevance assessment has occurred. The source-selected set is small and cannot establish general product accuracy. Six prior Phase 2 topics belong only to development. No relevance label may be changed in response to retrieval output in this run.

Freshly index all 20 PDFs separately with 256, 512, and 1024 token windows, 64 token overlap, page boundaries preserved, exact pinned EmbeddingGemma 2 checkpoint and BF16 CUDA configuration. Store native 768-dimensional normalized vectors. Compare leading 768/512/256/128 dimensions, re-normalizing both queries and passages after truncation, with no further neural inference for the dimension sweep. Encode each evaluation query once at 768 dimensions and reuse it across all methods/configurations. Do not count ranking-only latency as end-to-end latency.

Methods: (1) keyword counts distinct non-stoplisted query words in each passage, (2) original Phase 2 FTS5 BM25 with unfiltered query terms, (3) FTS5 BM25 with Porter English stemming, fixed query stop list, text/title weights 1.0/0.3, (4) cosine semantic search, (5) weighted reciprocal rank fusion of semantic and improved BM25 page rankings. One best passage per physical page; stable chunk-ID tie break. RRF uses 100 candidate pages per method. No query rewriting, reranking model, answer generation, or learned relevance threshold.

Select RRF semantic weight from {0.25, 0.5, 0.75}, rank constant from {10, 60}, chunk size from {256, 512, 1024}, and dimension from {768, 512, 256, 128} using development queries only. Maximize mean page Recall@5, then Recall@3, then MRR@5; final ties prefer smaller stored vector bytes and larger chunks. Write the selected configuration and label/corpus SHA256 digests before opening the test rankings. Test labels are used only for scoring and diagnostics, never configuration selection. The default CLI fusion remains fixed at 0.5/60 until explicitly configured; report evaluated settings exactly.

Macro page Recall@k is the fraction of all labeled distinct (document, physical page) pairs retrieved in the first k pages, averaged over answerable queries. Hit@k is the fraction of queries with any labeled page in the first k; report separately. MRR@5 is the mean reciprocal rank of the first labeled page, zero when absent from the top five. User acceptance targets are applied to **page Recall**, not substituted hit rate: Recall@5 >= 0.90 and Recall@3 >= 0.80 on the test split for the development-selected hybrid configuration. Report all other configurations descriptively; do not select the best test score and call it held-out performance.

No-answer questions have undefined recall and are excluded from positive metrics. Report how many still return candidates, maximum cosine scores, and the resulting false-positive behavior. These are candidate retrieval systems with no calibrated rejection policy; returning passages is not proof of a reliable answer. Empty folders must return no candidates and do no inference. Duplicate upload, scanned/empty/malformed PDFs, folder scope, persistence, and corruption defenses must retain their real-engine regression checks.

Measure fresh indexing time (cold model load reported separately), embedding time, chunk/page throughput, index/vector/PDF bytes, parent-process RSS and Torch GPU peaks. Sample warm end-to-end Library.search calls, including query inference and database reads/checks, and report mean/p50/p95/max. Query reuse for ablations must be explicit. Verify all persisted vectors and passage offsets against source physical pages; graphical viewer navigation remains untested until a viewer exists. Use existing extracted text and render selected difficult source pages for inspection.

If targets are missed, preserve the failed gate, inspect representative failures, and propose measurable next experiments. Do not progress to UI or Android on a quality failure.
